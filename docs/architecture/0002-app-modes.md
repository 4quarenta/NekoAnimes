# ADR 0002 — Modos Streaming e News

## Objetivo

A experiência visual pode operar em dois modos controlados pelo `app-manifest`.

### Streaming

Interface text-first:

- A–Z;
- busca;
- metadados;
- temporadas;
- episódios;
- player nativo.

### News

Somente notícias:

- feed;
- busca;
- salvos;
- artigos.

## Observação operacional

A configuração remota determina a experiência entregue. Publicação/distribuição deve sempre observar as regras aplicáveis das lojas e os requisitos de transparência funcional.
